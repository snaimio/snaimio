## 📱 About

Mobile developer based in Toronto, currently in the **Mobile Web Developer Using AI** diploma program at **triOS College**. I build native apps on both major platforms — SwiftUI on iOS, Kotlin/Jetpack Compose on Android — and lean on AI tooling throughout the dev workflow rather than around it.

Currently working across:
- **iOS** — SwiftUI, SwiftData, WidgetKit, UserNotifications
- **Android** — Kotlin, Jetpack Compose, Room, Hilt, Retrofit, WorkManager
- **Foundations** — Java, Git/GitHub workflows, Figma for UI/UX
